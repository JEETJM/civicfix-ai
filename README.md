# CivicFix AI

CivicFix AI is an intelligent civic issue prioritization and resolution tracking platform built using the MERN stack.

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Cloudinary
- Brevo Email OTP
- Leaflet + OpenStreetMap

## Core Features

- Citizen complaint reporting
- Image and location based complaint submission
- AI-assisted priority scoring
- Duplicate complaint detection
- Department auto-routing
- Public civic heatmap
- OTP-based complaint tracking
- Before/after resolution proof
- Escalation system
- Admin, Department Officer, Super Admin dashboards
