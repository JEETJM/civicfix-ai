📌 Project Overview

CivicFix AI is a full-stack smart civic complaint management platform where citizens can report local issues like roads, garbage, drainage, streetlights, waterlogging, public safety problems, and other civic issues.

The platform provides a complete workflow from complaint reporting to department assignment, resolution proof, status tracking, feedback, and analytics.

It is designed as a hackathon-ready MERN stack project with real-world civic-tech workflow and professional UI.
