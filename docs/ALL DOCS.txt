User Registration Workflow```txtUser opens Register page↓Selects role: Citizen / Department Officer / Admin Request↓Enters profile details↓Uploads optional profile image↓Account is created
Citizen and Department Officer:
Can login immediately
Admin:
Status becomes PendingCannot login until Super Admin approves
Super Admin:
Not publicly registeredCreated manually or using seeder

2. Admin Approval Workflow
User registers as Admin Request↓Account status = Pending↓Admin tries login↓System blocks login↓Super Admin opens Manage Users↓Super Admin approves or rejects↓If approved, admin can login↓If rejected, admin remains blocked

3. Complaint Reporting Workflow
Citizen logs in↓Opens Report Issue↓Enters title, description, category, location↓Uploads image↓System creates complaint↓AI priority score is generated↓Department route is selected↓Complaint is stored in database↓Citizen can view complaint in My Complaints

4. AI Complaint Analysis Workflow
Complaint title + description submitted↓AI scoring utility checks urgency keywords↓Category and department are mapped↓Priority score is calculated↓Urgency level is assigned↓Complaint receives AI analysis result
Output:
AI ScoreUrgencyDepartmentCategory

5. Admin Complaint Workflow
Admin logs in↓Opens Admin Dashboard↓Opens All Complaints↓Reviews complaint↓Verifies issue↓Assigns or reassigns department↓Adds admin remark↓Status becomes Assigned to Department

6. Department Officer Workflow
Department Officer logs in↓Opens Department Dashboard↓Views assigned complaints↓Opens complaint work panel↓Updates status to In Progress↓Adds work remark↓Uploads before proof↓Completes work↓Uploads after proof↓Marks complaint as Resolved

7. Complaint Status Flow
Normal flow:
Submitted↓AI Analyzed↓Duplicate Checked↓Assigned to Department↓In Progress↓Resolved↓Closed
Problem flow:
Assigned to Department / In Progress↓Escalated↓Admin / Super Admin Review↓Reassign / Follow up / Resolve

8. OTP Forgot Password Workflow
User opens Forgot Password↓Enters registered email↓System generates OTP↓OTP is stored in MongoDB↓OTP is sent to Gmail using Brevo SMTP↓User opens Reset Password↓Enters OTP and new password↓System verifies OTP↓Password is updated

9. OTP Complaint Tracking Workflow
User opens Track Complaint↓Enters Complaint ID and registered email↓System checks complaint owner↓System generates OTP↓OTP is stored in MongoDB↓OTP is sent to Gmail using Brevo SMTP↓User enters OTP↓System verifies OTP↓Complaint details and timeline are shown

10. Feedback Workflow
Complaint becomes Resolved↓Citizen opens complaint details↓Feedback form becomes visible↓Citizen gives rating and comment↓Feedback is stored↓Citizen trust score updates↓Admin can view feedback

11. Escalation Workflow
Manual escalation:
Admin reviews complaint↓Complaint is urgent or delayed↓Admin escalates complaint manually↓Escalation log is created↓Super Admin/Admin reviews it
Auto escalation:
System checks unresolved complaints↓Critical issue pending too long↓Complaint becomes Escalated↓Escalation log is created

12. Heatmap Workflow
Complaints are created with location↓System groups complaints by area↓Complaint density is calculated↓Heatmap shows civic issue hotspots
Zones:
Green = Low issue densityYellow = Medium issue densityRed = High issue density
